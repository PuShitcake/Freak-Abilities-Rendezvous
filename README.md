These abilities were made for **TFOC Network's Freak Fortress 2 server**.
I'm making them public because, honestly, I'm having more fun playing **Deadlock** these days. If you happen to stumble across this repo, help yourself!

I might get around to replying when I'm free or have nothing better to do.

Have fun, and keep enjoying Freak Fortress 2!
